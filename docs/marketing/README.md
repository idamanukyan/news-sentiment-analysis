## Positioning guardrails (keep these when editing)

- **No invented metrics.** Figures describe platform *capability*, never audience/traffic numbers we don't have.
- **Armenia is the case study, not a customer win** — the deployment is proof of capability, framed honestly.
- **Name:** "AIIM — AI Information Integrity Monitor" (the "Armenia" expansion is retired; `aiim.am` kept).
- Grant page marks the application round / licence as "to be confirmed" until verified (see funding-research ticket).
