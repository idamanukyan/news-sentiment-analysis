The public-interest problem

Monitoring disinformation is public-interest work done by hand

Foreign information manipulation and interference (FIMI) is a standing threat to democratic discourse — coordinated narratives on energy, migration, elections and war move across news, Telegram and social platforms across multiple languages at once.

The people defending against it — fact-checkers, disinformation researchers, civil-society organisations, small newsrooms — mostly work manually: watching channels by hand, tracking narratives in spreadsheets, writing reports from scratch. The tooling that could give them a continuous, cross-lingual picture is either locked inside expensive commercial products or does not exist as open, auditable infrastructure the community can trust and extend.

What gets built in the funding period

An open-source FIMI-detection core

A working platform already exists (see below). The Prototype Fund period funds carving out and hardening the parts most useful to the community as free, reusable software.

1

Cross-lingual narrative detection

Open module that clusters articles/posts into narratives across languages using keyword and AI relevance scoring — with German added alongside the existing Russian/English/Armenian coverage.

2

Coordination-detection engine

Transparent, documented method for flagging when the same narrative is pushed in lockstep across sources (timing + content similarity) — the signal that separates an organic story from an operation.

3

Open reporting & data export

Export of narratives, coordination events and evidence in open formats (CSV, JSON, Markdown) plus DSA-compliance report templates, so researchers and watchdogs can build on the output.

4

Documentation & reproducibility

Public repository, setup docs and methodology write-up under a free licence, so any civil-society team can self-host and audit how detection works.

Why open source

Trust in a monitoring tool requires seeing how it decides

A system that labels content as "coordinated" or "high-threat" is making consequential judgements. For that to be legitimate in a democratic context, the method has to be inspectable, contestable and reusable — not a black box sold per seat. Open-sourcing the detection core lets researchers validate it, lets civil-society groups run it on their own infrastructure under their own data governance, and lets the community improve it. Public-interest monitoring should sit on public infrastructure.

Proven capability — not starting from zero

Already built and deployed against a live information war

AIIM was developed and deployed to monitor the information environment around a contested national election, ingesting and analysing sources continuously across Russian, Armenian and English — the demanding, Kremlin-adjacent, multilingual conditions this problem actually shows up in. The funding turns a proven working system into open, community-owned infrastructure.
